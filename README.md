# WakeUpThroughServer

Telegram-бот для удалённого управления ПК: включение через Wake-on-LAN, проверка статуса, выключение и перезагрузка по SSH.

## Возможности

- **Wake-on-LAN** — отправка magic packet для включения ПК
- **Статус** — проверка доступности ПК через ping
- **Выключение / Перезагрузка** — через SSH с подтверждением
- **Контроль доступа** — только разрешённые пользователи

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `ALLOWED_USERS` | ID разрешённых пользователей через запятую |
| `PC_MAC` | MAC-адрес ПК для WoL |
| `PC_IP` | IP-адрес ПК в локальной сети |
| `PC_NAME` | Отображаемое имя ПК |
| `PC_SSH_USER` | Имя пользователя для SSH-подключения |

## Запуск

```bash
python bot.py
```

## Требования

- Python 3.10+
- SSH-доступ к целевому ПК (для выключения/перезагрузки)
- Wake-on-LAN включён в BIOS целевого ПК
